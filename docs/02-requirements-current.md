# 02 — Confirmed & current requirements

This is the list of requirements that were **confirmed by the owner** (asked
for directly, or accepted when proposed) and their **status in the code as
of 2026-09-29** (last commit `8e796c9 "profile card added"`).

Legend: ✅ done · ⚠️ partly done · ❌ not done

For the reasoning behind each item see [12-decision-log.md](12-decision-log.md);
for exact numbers see [08-business-rules.md](08-business-rules.md).

| Requirement | Status | Notes |
